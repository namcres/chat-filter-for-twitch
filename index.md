# Privacy Policy for Chat Filter for Twitch

**Effective Date:** November 23, 2026

## 1. Overview
Chat Filter for Twitch is a browser extension designed to collapse and filter messages in Twitch chat. Your privacy is important, and this extension is built to function without collecting personal information.

## 2. Data Collection and Storage
* **No Personal Data Collected:** This extension does not collect, transmit, or sell any personal data, browsing history, or Twitch account information to external servers or third parties.
* **Local Storage Only:** Any preferences or settings you configure (such as filter rules or toggle states) are stored strictly locally on your device using your browser's built-in storage API (`chrome.storage` / `localStorage`).

## 3. Third-Party Services
This extension interacts locally with the webpage DOM on `twitch.tv` solely to modify how chat messages are displayed in your browser. It does not send data to Twitch or any analytics providers.

## 4. Changes to This Policy
If future updates change how data is handled, this policy will be updated on this page with a revised effective date.

## 5. Contact
If you have questions about this privacy policy, you can open an issue on this GitHub repository or contact the developer at namcresgames+questions@gmail.com.
